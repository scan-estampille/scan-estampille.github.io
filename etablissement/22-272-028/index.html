Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 22.272.028 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 22 est le numéro du département (Côtes-d’Armor), 272 le code de la commune et 028 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
