Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 59.225.104 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 59 est le numéro du département (Nord), 225 le code de la commune et 104 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
