Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 11.262.047 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 11 est le numéro du département (Aude), 262 le code de la commune et 047 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
