Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 22.278.003 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 22 est le numéro du département (Côtes-d’Armor), 278 le code de la commune et 003 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
