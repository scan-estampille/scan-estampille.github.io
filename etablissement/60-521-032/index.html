Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 60.521.032 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 60 est le numéro du département (Oise), 521 le code de la commune et 032 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
