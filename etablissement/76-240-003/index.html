Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 76.240.003 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 76 est le numéro du département (Seine-Maritime), 240 le code de la commune et 003 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
