Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 87.065.001 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 87 est le numéro du département (Haute-Vienne), 065 le code de la commune et 001 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
