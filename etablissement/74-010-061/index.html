Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 74.010.061 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 74 est le numéro du département (Haute-Savoie), 010 le code de la commune et 061 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
