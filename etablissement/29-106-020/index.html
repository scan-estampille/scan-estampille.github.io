Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 29.106.020 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 29 est le numéro du département (Finistère), 106 le code de la commune et 020 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
