Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 49.099.002 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 49 est le numéro du département (Maine-et-Loire), 099 le code de la commune et 002 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
