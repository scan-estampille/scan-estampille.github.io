Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 33.036.001 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 33 est le numéro du département (Gironde), 036 le code de la commune et 001 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
