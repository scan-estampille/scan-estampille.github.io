Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 81.004.011 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 81 est le numéro du département (Tarn), 004 le code de la commune et 011 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
