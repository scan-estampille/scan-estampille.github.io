Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 94.065.035 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 94 est le numéro du département (Val-de-Marne), 065 le code de la commune et 035 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
