Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 22.061.015 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 22 est le numéro du département (Côtes-d’Armor), 061 le code de la commune et 015 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
