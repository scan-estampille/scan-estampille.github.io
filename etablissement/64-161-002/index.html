Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 64.161.002 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 64 est le numéro du département (Pyrénées-Atlantiques), 161 le code de la commune et 002 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
