Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 72.080.002 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 72 est le numéro du département (Sarthe), 080 le code de la commune et 002 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
