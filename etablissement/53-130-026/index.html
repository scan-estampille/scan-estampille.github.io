Lire l’estampille sanitaire

Sur l’emballage, l’estampille ovale FR 53.130.026 CE indique que le produit a été fabriqué ou conditionné en France dans cet établissement : 53 est le numéro du département (Mayenne), 130 le code de la commune et 026 le numéro de l’établissement. « CE » signifie que l’agrément sanitaire est reconnu dans toute l’Union européenne.
